# Fred Conciergerie — Carnet de Prestataires

Une application web simple et élégante pour gérer votre carnet de prestataires.

## Fonctionnalités

✅ **Ajouter des prestataires** - Nom, catégorie, spécialité, téléphone, zone, langues, tarif, niveau de confiance

✅ **Filtrer par catégorie** - Chauffeurs, Chefs privés, Sécurité, Yachts & Jets, Villas, Événementiel, Autres

✅ **Rechercher** - Par nom, spécialité ou zone d'intervention

✅ **Appeler directement** - Bouton "Appeler" pour les appels téléphoniques

✅ **WhatsApp** - Lien direct pour contacter via WhatsApp

✅ **Supprimer** - Supprimer un prestataire de la liste

✅ **Sauvegarde locale** - Les données sont stockées dans le navigateur (localStorage)

## Utilisation

1. Ouvrez `index.html` dans votre navigateur
2. Cliquez sur "+  Ajouter un prestataire"
3. Remplissez les informations
4. Cliquez sur "Enregistrer"
5. Les prestataires s'affichent immédiatement

## Stockage

Les données sont sauvegardées dans **localStorage** de votre navigateur. Elles persisteront même après la fermeture du navigateur.

## Couleurs

- **Fond** : #14120E (noir très foncé)
- **Cartes** : #1E1B15 (brun très foncé)
- **Or** : #C6A15B (couleur principale)
- **Texte** : #F3EEE3 (ivoire)

## Design Responsive

L'app est optimisée pour mobile (max-width: 480px) mais fonctionne aussi sur desktop.
