# Fred Conciergerie — Site vitrine

## Structure du projet

```
fred-conciergerie/
├── index.html      → la page du site
├── styles.css       → tous les styles (couleurs, mise en page, animations)
├── script.js        → interactions (menu mobile, animations au scroll)
├── assets/
│   └── logo.png      → logo détouré (fond transparent)
└── README.md         → ce fichier
```

## Mettre le site en ligne (gratuit, avec GitHub Pages)

1. Crée un compte sur [github.com](https://github.com) si tu n'en as pas
2. Crée un nouveau repository (Public)
3. Uploade **tous les fichiers de ce dossier** en gardant la structure
   (glisser-déposer tout le dossier fonctionne, GitHub garde les sous-dossiers)
4. Va dans **Settings → Pages**, choisis la branche **main**, dossier **/ (root)**, puis **Save**
5. Après 1-2 minutes, ton site est en ligne à une adresse du type :
   `https://tonpseudo.github.io/fred-conciergerie/`

## À modifier avant mise en ligne

- **Email de contact** : cherche `contact@fred-conciergerie.fr` dans `index.html` et remplace par la vraie adresse
- Le numéro de téléphone est déjà à jour (06 16 54 54 18)

## Modifier le site ensuite

- **Textes / structure** → `index.html`
- **Couleurs / styles / espacements** → `styles.css` (les couleurs principales sont en haut du fichier, dans `:root`)
- **Comportements (menu, animations)** → `script.js`
- **Logo** → remplace `assets/logo.png` par une nouvelle version (garde le même nom de fichier)
