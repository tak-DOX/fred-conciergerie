# To-Do List - Gestionnaire de Tâches

Une application web moderne et élégante pour gérer vos tâches quotidiennes.

## 🎯 Fonctionnalités

✅ **Ajouter des tâches** - Créez des tâches avec priorité (Basse, Moyenne, Haute)

✅ **Cocher les tâches** - Marquez les tâches comme complétées

✅ **Filtrer** - Filtrez par statut ou priorité (Toutes, En attente, Complétées, Haute priorité)

✅ **Supprimer** - Supprimez les tâches que vous n'avez plus besoin

✅ **Statistiques** - Voir le nombre total, en attente et complétées

✅ **Barre de progression** - Visualisez votre avancement

✅ **Sauvegarde locale** - Vos tâches sont automatiquement sauvegardées

## 📱 Comment utiliser

1. Ouvrez `todo.html` dans votre navigateur
2. Tapez une tâche dans le champ d'entrée
3. Sélectionnez la priorité (Basse, Moyenne, Haute)
4. Cliquez sur "+ Ajouter" ou appuyez sur Entrée
5. Cochez les tâches pour les marquer comme complétées
6. Filtrez vos tâches selon vos besoins
7. Les tâches sont sauvegardées automatiquement !

## 🎨 Design

- **Thème sombre** moderne avec dégradés
- **Couleurs intuitives** : Bleu pour l'action, Rouge pour danger, Vert pour succès
- **Responsive** : Fonctionne parfaitement sur mobile et desktop
- **Interface fluide** : Animations douces et transitions élégantes

## 💾 Stockage

Toutes les tâches sont stockées dans **localStorage** de votre navigateur. Elles persisteront même après la fermeture de la page.

## 📊 Statistiques

L'app affiche en temps réel :
- Nombre total de tâches
- Tâches en attente
- Tâches complétées
- Barre de progression visuelle
